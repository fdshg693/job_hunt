# 海外転職 問いのバックログ・決定ログ

> 海外 track の調査は「答えが出ると何かが決まる問い」から始める。調べものはこの表の問いに紐づけ、答えが出たら決定を記録して [`strategy.md`](strategy.md) / [`criteria.md`](criteria.md) / [`roadmap.md`](roadmap.md) に反映する。
>
> - 調査結果の本体は `research/countries/{iso2}.md`・`research/market/` に書き、ここには **答えの要約・根拠リンク・決定** だけを書く。調査ファイルのフロントマターには `answers: ["Q-01"]` のように問い ID を書く。
> - 制度情報（ビザ・税）は一次情報（政府・公的機関）の URL と確認日を根拠にする。
> - 状態: `open` / `investigating` / `answered` / `dropped`
