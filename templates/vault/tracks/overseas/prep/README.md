# 面接対策メモ (prep/)

海外選考に向けた対策メモを置く。準備の全体像と時期は [`../roadmap.md`](../roadmap.md)。

- **ファイル名**: `{category}_{topic}.md`
  - `category`: `english`（英語スピーキング・自己紹介）、`coding`（コーディング面接）、`system-design`（システムデザイン面接）、`behavioral`（行動面接・STAR）、`resume`（英文レジュメ）
  - 例: `english_self-introduction.md`, `behavioral_star-stories.md`, `system-design_url-shortener.md`
- **フロントマター**:

```yaml
---
category: "behavioral"
topic: "STAR ストーリー集"
updated_at: "YYYY-MM-DD"
status: "drafting" # drafting | practicing | ready
---
```

- **本文の目安**: 想定質問 → 回答の骨子（英語） → 練習ログ（日付・気づき） → 改善点。
- 実績エピソードの素材は `vault/profile/en/skills.md`（英語版 STAR 実績集）を正本とし、ここでは面接用の言い回し・練習記録だけを持つ。`visibility: internal` のファイルの内容は回答文に含めない。
