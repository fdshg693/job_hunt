# 海外転職 track (overseas)

## track の定義

- **対象**: 日本国外の法人に雇用・契約される就業。**現地就労・リロケーション・日本在住のまま海外企業へフルリモート勤務（雇用・業務委託・EOR 経由を含む）**をすべて含む。
- 外資系企業でも**日本法人に雇用される場合は `domestic`** track で扱う。

## 期間・目標

- **期間**: （例: 1〜2年以内）
- **目標**: （例: ビザが取りやすい英語圏で現地就労、または海外法人にフルリモートで就業する）
