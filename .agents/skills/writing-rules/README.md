# writing-rules スキルについて

`writing-rules` は Google Antigravity の `.agents/rules/*.md` ルールファイルの新規作成・修正・一括初期化を扱うスキルである。このファイルは人間のメンテナ向けで、統合の経緯と、本文中の例示が指すものの注意点をまとめる。Antigravityエージェントが実行時に読むのは [SKILL.md](SKILL.md) であり、こちらは参照しない。

## 統合の経緯

このスキルは元々 `writing-rules`（1件のルールの作成・修正）と `init-rules`（未文書化プロジェクトの一括初期化）という2つの別スキルだった。両者は「ルールファイルのファイル形式・粒度の基準」を共有する必要があるにもかかわらず別々のSKILL.mdに存在していたため、片方だけ基準を更新するとドリフトするリスクがあった。1スキルに統合し、ファイル形式・粒度の基準を [writing.md](writing.md) に一本化、一括初期化に固有の発見戦略・サブエージェント委譲だけを [init.md](init.md) に残す構成にした。

また、Antigravity のメモリ設計（`.agents/rules/*.md`、`GEMINI.md`、`AGENTS.md`）に合わせてフォーマットやパスを更新している。メモリ全体の使い分けや仕様詳細は `antigravity-memory` スキルと整合している。

## `init.md` が明示的な依頼を要求する理由

`init.md` はプロジェクト全体をスキャンし、サブエージェントに委譲して複数のルールファイルを一括生成/更新する高コストな操作である。誤って自動起動すると、既存のルールファイルを意図せず大量に書き換えてしまうリスクがある。そのため `init.md` 自体の冒頭で「明示的に初期化/ブートストラップを依頼されたのでなければ、実行前にユーザーに確認する」と明記しており、`SKILL.md` のルーティングもこの前提を崩さない（未文書化プロジェクトかどうかの判定だけで自動的にinit.mdの全体フローへ突入させない）。

## `writing.md` の例示パスは他プロジェクト由来である

[writing.md](writing.md) のファイル形式の例（`src/FinLearn.Core/Models/Foo.cs`、`docs/FEATURES/Foo/LOGIC.md` など）は、このAIツール研究リポジトリ自身の構造ではなく、別プロジェクト（FinLearn）でこのスキルを最初に書いた際の実例をそのまま一般化したものである。このリポジトリ自体には `FinLearn.Core` のようなディレクトリは存在しない。

将来このスキルを編集する際、例示パスを「このリポジトリの実際の構造」と誤解して同期を取ろうとしないこと。例示はあくまで「トリガー条件（`globs:`等）＋短い本文＋`docs/`への誘導や`@`参照」という**形式**を示すためのものであり、具体的なパス名に意味はない。もし将来的にこのリポジトリ自身の実例（例: `.agents/rules/` 配下の既存ファイル）に差し替えた方が分かりやすいと判断したら、`writing.md` 側を書き換えてよい。

## ファイル構成

```text
writing-rules/
├── SKILL.md      # 「1件の作成/修正」か「全体初期化」かの分岐のみ
├── README.md     # このファイル(人間向け設計意図)
├── writing.md    # ファイル形式・粒度・スタイルの基準(正)。通常ケースの手順
└── init.md       # 全体初期化時の発見戦略・サブエージェント委譲テンプレート(形式面はwriting.mdに従う)
```

## 保守時の注意

- ファイル形式・粒度の基準を変更する場合は [writing.md](writing.md) だけを更新する。[init.md](init.md) は基準を重複して書かず、常に「詳細は `writing.md`」と参照する構成を保つこと。
- `init.md` のサブエージェント委譲テンプレート内の指示文言（`writing.md` を読ませる一文など）を変更したら、`writing.md` のパスやファイル名が変わっていないか実際に確認する。
- Antigravity のメモリ設計や最新仕様の変更については [antigravity-memory](../antigravity-memory/SKILL.md) および [antigravity-docs](../antigravity-docs/SKILL.md) を参照すること。
